# ADR-001：首期采用模块化单体与独立 Worker

- 状态：Accepted
- 日期：2026-08-02

## 决策

在线 Search/Feed 采用一个可多副本部署的 Spring Boot 进程，内容控制面采用独立进程，资源密集与异步任务由 Worker、Flink 和训练 Runner 承担。业务边界由九个 Context 模块和六边形依赖规则保证。

## 原因

Phase 0/1 的规模尚不足以抵消全面微服务带来的部署、契约、观测和一致性成本，但内容处理、实时计算与在线请求有明确的资源隔离需求，因此先拆进程形态，不拆所有业务 Context。

## 后果

应用装配层会依赖多个 Context；Context 不共享可变实体；基础设施通过输出 Port 接入。未来满足独立扩缩容、发布或故障隔离条件时，可沿 Context 边界拆分。
